# Kanban Board

A task management application built with React and TypeScript that helps organize tasks into workflow stages, manage priorities, and track progress using a Kanban board. 

## Live Demo

[View Live Application](https://kanbanboardbyc5k.netlify.app/)

## GitHub Repository

[View Source Code](https://github.com/ShankarlaaLC5K/KanbanBoardByC5K)

## Features

- Organize tasks into To Do, In Progress, and Done columns
- Add tasks to selected columns
- Edit and delete tasks
- Drag and drop tasks between columns
- Reorder tasks within columns
- Assign High, Medium, and Low priorities
- Flag important tasks
- View task details in a modal
- Save tasks using browser localStorage
